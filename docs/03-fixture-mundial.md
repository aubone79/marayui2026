## Notas sobre banderas

Para representar países usá emojis de bandera. NO uses escudos de federaciones ni logos. Si un emoji de bandera no renderiza bien en algún sistema (típicamente Windows), aceptable degradar a un círculo de color con el código de país (`AR`, `UY`, etc.) en monoespaciada.

Inglaterra es la excepción más rara — el emoji `🏴󠁧󠁢󠁥󠁮󠁧󠁿` no siempre renderiza. Fallback: las letras `ENG` en una píldora.
